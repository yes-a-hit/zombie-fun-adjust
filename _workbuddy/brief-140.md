# 1.4.0 图鉴文案 · brief

你是文案作者。规则与上一版（`brief.md`）完全一致：**宝开语、中英双语、先正经后拆台**。
只写文案，不动数值、不动 codename。

## 输出格式

每批一个 JSON 文件：

```json
{
  "zombies": [
    {
      "codename": "...",
      "name": { "en": "...", "zh": "..." },
      "intro": { "en": "...", "zh": "..." },
      "special": [
        { "name": { "en": "Special", "zh": "特点" }, "desc": { "en": "...", "zh": "..." } }
      ],
      "chat": { "en": "...", "zh": "..." }
    }
  ]
}
```

- `name` 只有需要改名的条目才写，其余省略。
- `special` 数组整体替换：原有仍然成立的技术条目要保留并改写得顺，**新增一条**写本次改动。
- `chat` 中文 100~200 字，英文按 PopCap 英文图鉴腔重写，不是直译。
- 不要代码围栏，JSON 必须能 `JSON.parse`。

## A 组 → 写入 `batchA-140.json`

### 1. `dark_gargantuar` 黑暗巨尸

**本次改动**：他击杀任何单位 —— 不管是植物还是僵尸（包括自己扔出去的僧侣小鬼）—— 立刻回复 900 血。

原作设定：巨尸总能一锤定音；用石锤摧毁植物；受重伤时丢出僧侣小鬼。

**必须写的梗**：**诺克萨斯断头台**。
这是《英雄联盟》里诺克萨斯之手德莱厄斯的大招：跳起来一斧子处决，**击杀目标后可以立刻再次施放，并且回血**。
把他的「击杀回血」对到这上面——他砸死一个就精神一振，于是接着砸下一个。梗要自然嵌进 Chat，不要生硬报菜名（不要写成「他的技能是诺克萨斯断头台」），要让读者自己反应过来。

### 2. `lostcity_crystalskull` 青骷髅头僵尸 → 改名「老爹」

**本次改动**：改名。中文 **老爹**，英文 **Uncle**。
**必须写的梗**：《成龙历险记》里的老爹（Uncle Chan 的叔叔，古董店老先生）。
可用素材：口头禅「还有一件事……」（说走又回头）、「哎呀呀」、「要用魔法打败魔法」、
执念于「魔法」、泡茶、以及永远在别人要走的时候再补一句。

原作机制照旧：用骷髅头偷走阳光蓄能，再发射一道致命激光；会尝试偷阳光；偷走的阳光不返还。

要求：`name` 字段写 `{"en":"Uncle","zh":"老爹"}`；`intro` 要把「偷阳光」这件事和他的性格绑起来
（他偷阳光大概有自己的道理）；`special` 保留原两条技术描述 + 一条本次改名说明；`chat` 是老爹梗的主场。

## B 组 → 写入 `batchB-140.json`（5 条）

### 3. `beach_fisherman` 渔夫僵尸

**本次改动**：甩钩的结果改成抽奖——
- 10%：用力方向搞反了，**把自己往前拽一格**（朝着植物的方向滑过去）；
- 20%：用力过猛，**自己掉 100 血**；
- 20%：**完全没反应**，钩子空转一圈收回来；
- 其余 50%：照旧把植物往回拉（相邻植物照样直接甩出草坪）。

**必须写的**：图鉴里要有一段把他归成「**空军类**」的描述——
他明明蹲在草坪上甩钩子，却坚持自己属于空军（干的是远程牵引作业），
可以拿「空军」这个编制梗写：装备、番号、体检、僚机之类。别解释得太满，点到就停。

原作机制保留：把植物向右拉走；相邻植物直接被甩出草坪。

### 4~7. 被投手爆头的四只（各一条）

共同改动：**受到投手类植物（卷心菜投手 / 玉米投手 / 西瓜投手 / 辣椒投手 / 冬瓜子这一类的抛投）伤害 ×4**。
用一句话概括就是「被投手直接爆头了」。

| codename | 中文名 | 图鉴里要点到的部位 |
|---|---|---|
| `future_gargantuar` | 巨尸统领者 | 驾驶舱 / 机械头（激光眼那块） |
| `catapult` | 投石车僵尸 | 车斗里那颗脑袋（他本来就是往你后排砸篮球的，现在轮到自己被砸头） |
| `zomboni` | 造冰车僵尸 | 挡风玻璃后面的驾驶位 |
| `sky_twin` | 双舱飞行僵尸 | 两个机舱（本体设定是「两个机舱全部被击毁后才会坠落」） |

每条的 `intro` 保留原作对机制的描述，`special` 保留原有技术条目 + 新增一条写 4 倍伤害，
`chat` 写「爆头」这件事的幽默版本（可以拿各自的职业身份开涮：司机、投手、飞行员）。
不需要解释「为什么是 4 倍」，但要让读者感到「难怪一投手下去它就没了」。
