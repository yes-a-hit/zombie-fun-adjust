# Zombie Fun Adjust · 妙趣横生的僵尸调整

> 针对僵尸的体验调整：削弱几个让人血压升高的机制，
> 让脉冲黄桃真正拦得住空中之城的飞机，并给重金属巨人的舞台效果补上实打实的一击。

| | |
|---|---|
| 版本 | 1.1.0 |
| 适配 | PvZ2 Gardendless 0.15.0 + GP-Next 1.5.0-pre.1 |
| 前置 | 无（需要开启 JavaScript 模组） |
| uuid | `yg.zombie-fun-adjust` |

## 改动一览

| # | 对象 | 改动 |
|---|---|---|
| 1 | **全部小鬼** | 血量统一 → **95** |
| 2 | **脉冲黄桃** | 瘫痪并**强制落地**所有飞机（僵王除外） |
| 3 | **重金属巨人** | 舞台效果期间改为直接扔小鬼，数量不限 |
| 4 | **街机游戏机** | 不再召唤像素铁桶，且每次召唤自扣血 |
| 5 | **轮滑（闪耀）僵尸** | 踩到地刺一击必杀 |
| 6 | **霹雳舞僵尸** | 一次只踢一只，踢完自扣 50 血 |
| 7 | **麦克说唱家** | 甩完麦克风自杀 |
| 8 | **章鱼僵尸** | 每投掷一次自扣 150 血 |
| 9 | **弄臣** | 旋转期间每秒掉 20 血 |

### 逐条说明

**1. 小鬼血量统一为 95**
18 只带独立血量的「小鬼」全部下调，含未来世界的机械虫小鬼。
小鬼炮是炮台装置、不在此列；节日系九只小鬼没有独立血量，会跟着普通小鬼一起变 95。
效果上：5 发豌豆一只。

**2. 脉冲黄桃瘫痪并强制落地所有飞机**
覆盖小鬼飞机、单体战斗机、双体战斗机、无人机、裁决者五类。
引擎里脉冲黄桃对范围内目标调用 `zombie.empStun()`，而**基类该方法是空函数** ——
全引擎只有 12 处覆写，飞行僵尸里仅有无人机有份，其余四类原本完全免疫。
现在五类全部补上覆盖，并借 `flying = false` 触发引擎的落地回调实现强制落地。
**僵王不在目标之列。**

**3. 重金属巨人舞台效果改为扔小鬼**
挥锤的原音波移除后这里本是"空 A"，现在舞台效果（Jam）期间改为**直接扔小鬼**，
且每次投掷前把携带数补满 —— **不受「每巨人一只」的限制**。
非舞台期间保持普通砸击不变。

**4. 街机游戏机**
召唤池只剩「像素僵尸 / 像素路障」，不再出像素铁桶；
每召唤出一只，机器自身扣 **100** 血。

**5. 轮滑（闪耀）僵尸**
踩到地刺直接死亡，地刺本身不掉血——和引擎里钢琴、滚桶那类载具僵尸同一套写法。

**6. 霹雳舞僵尸**
原本一次能把 1.5 格内的僵尸**全部**踢飞。现在只踢一只；
踢中之后自己扣 **50** 血（空踢不扣）。

**7. 麦克说唱家**
甩完麦克风后自杀。**攻击伤害照常结算**，只是甩完自己倒下。

**8. 章鱼僵尸**
每扔一次章鱼自扣 **150** 血。

**9. 弄臣**
旋转期间持续掉血，每秒 **20** 点。按 420 点血算，大约转十次就会自己倒下。

## 快速开始

1. 游戏内按 `F12`，在 Console 执行一次 `await gpNext.mods.enableJsModding()`
2. 取得安装包 ZIP —— 在 **Releases** 页面下载，或克隆本仓库后运行 `npm run pack` 自行打包
3. GP-Next 侧栏 → **模组** → **导入 ZIP**，选中上一步得到的 zip
4. **在模组列表里把它勾上**（导入后默认不勾，**不勾等于没装**）
5. 点 **保存并应用**，按提示重启游戏

**不需要任何额外脚本、命令行或补丁工具。**

> **第 4 步最容易漏。** 包导入后在 `installed/` 和配置里都在，但 `enabled` 是 `false`，
> 此时 JS 一行不跑、数值补丁一条不生效，表现就像"没装"。

遇到问题见 [`docs/INSTALL.md`](docs/INSTALL.md)（含一份常见故障排查表）。

## 生效确认

装好后可以这样快速验证：

- **小鬼**：5 发豌豆一只
- **脉冲黄桃**：放到飞机下方引爆，飞机会当场落地；无人机直接坠毁
- **重金属巨人**：舞台效果期间会不停扔出小鬼，且能反复扔
- **街机**：只召唤像素僵尸 / 像素路障，且每次召唤机器自己掉血
- **轮滑**：踩地刺直接死
- **霹雳舞**：一次只踢一只，踢完自己掉 50
- **RAP**：甩完麦自己倒下
- **章鱼**：扔一次掉 150
- **弄臣**：开始旋转后血条持续下滑

日志里搜 `僵尸调整`，能看到依赖解析结果与挂载数量。

## 项目结构

仓库根**同时就是模组根**——`pack.json` 在最顶层，所以 `git clone` 之后可以直接用
GP-Next 的「导入文件夹」选中仓库根，不需要额外构建步骤。

```
zombie-fun-adjust/
├── pack.json              GP-Next 模组清单
├── jsons/objects/         小鬼血量补丁（ZombieProps）
├── scripts/main.js        运行期入口：九条行为钩子（ESM）
├── tests/                 模拟验收测试（不需要游戏本体）
├── tools/pack.ps1         发布打包：白名单 + 校验 + 用产物复测
├── docs/
│   ├── INSTALL.md         安装、部署与排查
│   └── ENGINE-NOTES.md    引擎笔记：每条改动挂在哪、为什么
├── package.json           仅开发用（`type: module` + npm scripts）
├── LICENSE                MIT 全文
├── NOTICE.md              非代码内容的来源与归属
└── CHANGELOG.md
```

发布的 ZIP **只含运行时文件**
（`pack.json` + `README.md` + `LICENSE` + `NOTICE.md` + `jsons/` + `scripts/`），
`tests/`、`tools/`、`docs/`、`package.json` 等开发用文件不会进包——
`tools/pack.ps1` 用白名单控制，并会校验有没有漏进去、有没有漏掉必含项。

`LICENSE` 与 `NOTICE.md` 进包不是可选项：MIT 条款要求版权声明与许可声明
随软件的所有副本分发。

## 开发

需要 Node.js（跑测试）。打包需要 Windows PowerShell。

```bash
npm test        # 跑模拟验收测试
npm run pack    # 生成 dist/*.zip，并自动用打包产物复测一遍
```

打包脚本做四件事：白名单暂存 → 正斜杠 ZIP → 校验条目与清单字段 → 解包并用包里的
`scripts/main.js` 重跑同一套断言。等价的手动复测：

```bash
JBTMG_PKG_ROOT=<解包目录> JBTMG_ENTRY=<解包目录>/scripts/main.js node tests/run.mjs
```

测试细节见 [`tests/README.md`](tests/README.md)，每条改动的引擎依据见
[`docs/ENGINE-NOTES.md`](docs/ENGINE-NOTES.md)。

### 为什么测试可以脱离游戏跑

模组逻辑的核心是「钩子挂在哪、什么条件下改、什么时候还原」，这些在没有引擎时完全可测——
只要假类的类名、方法名、事件名与真机一致。`tests/harness.mjs` 里那张表是照
`docs/ENGINE-NOTES.md` 逐条核对过的；**改它之前先回引擎确认**，否则会出现
「测试通过、真机不触发」这种最贵的失败。

## 自定义

所有可调数值集中在 `scripts/main.js` 顶部的 `CFG`，改完跑一遍 `npm test` 即可：

| 想改什么 | 字段 |
|---|---|
| 街机每次召唤的自扣血 | `arcadeSummonSelfHit`（默认 100） |
| 霹雳舞踢中后的自扣血 | `breakdancerKickSelfHit`（默认 50） |
| 章鱼每次投掷的自扣血 | `octopusThrowSelfHit`（默认 150） |
| 弄臣旋转掉血速率 | `jesterRotateSelfHitPerSec`（默认 20/秒） |

小鬼血量是数据改动，改 `jsons/objects/ZombieProps.json` 里对应条目的 `Toughness`。

脉冲黄桃的落地目标名单在 `TARGETS` 里（`mode: 'empDrop'` 的六条），
重金属巨人的扔小鬼行为是 `mode: 'jamThrow'` 那一条。

游戏内的模组面板也能看到当前数值与各条钩子的挂载状态。

## 已知限制

- **脉冲黄桃的落地依赖 `flying` 访问器。** 若某类飞机不使用该字段，
  它仍会被瘫痪、但不会强制落地（日志与面板会照常计数）。
- **小鬼血量需要重启生效**（属于数据补丁）；其余为运行期钩子，
  只影响运行时新建或更新的对象。
- 若某个僵尸类在未来版本改了方法名，对应那条会挂载失败，
  日志与面板会明确写出是哪一个。
